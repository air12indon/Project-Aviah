One-time setup needed

This app needs a free Firebase backend so your Sales Rep and Online Ordering accounts can sync in real time. Do this once, from your phone browser:

  1. Go to console.firebase.google.com and sign in with a Google account.
  2. Tap Add project, name it anything (e.g. "pos-ordering"), finish creation.
  3. In the left menu: Build → Authentication → Get started → enable the Email/Password sign-in method.
  4. In the left menu: Build → Firestore Database → Create database → choose a location → start in test mode (we'll tighten rules after).
  5. Tap the gear icon → Project settings → scroll to "Your apps" → tap </> (Web) → register the app (any nickname).
  6. It will show a code block with apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId. Copy all 6 values.
  7. Send me those 6 values in chat — I'll embed them into this file and give you the finished version. No code editing needed on your end.

Once your config is embedded, also paste the security rules I'll give you into the Firestore "Rules" tab so only the right accounts can see the right data.
